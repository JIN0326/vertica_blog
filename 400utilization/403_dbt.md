## DBT 연동

<div class="architecture-section">
  <p class="section-description"><strong>dbt (Data Build Tool)</strong>는 데이터 분석가와 엔지니어가 SQL만으로 데이터 변환(Transformation) 파이프라인을 구축, 테스트, 배포할 수 있도록 돕는 오픈소스 도구입니다. Vertica와 dbt를 연동하면, 복잡한 데이터 모델링과 변환 작업을 체계적으로 관리하고 자동화할 수 있습니다.</p>

  <div class="architecture-subsection">
    <h3 class="section-subtitle">1. dbt 환경 구성</h3>
    <p class="section-description">Python 가상 환경을 생성하고, dbt와 Vertica 연동에 필요한 패키지를 설치합니다.</p>
    <div class="syntax-box">
      <strong>[as root] 가상 환경 생성 및 패키지 설치:</strong>
      <pre><code># 1. 개발 도구 및 Python 개발 라이브러리 설치
yum install -y python3-devel gcc git

# 2. Python 가상 환경 생성 및 활성화
cd /opt
python3 -m venv dbt-env
source /opt/dbt-env/bin/activate

# 3. dbt-core 및 dbt-vertica 어댑터 설치
pip install --upgrade pip
pip install dbt-core dbt-vertica</code></pre>
    </div>
  </div>

  <div class="architecture-subsection">
    <h3 class="section-subtitle">2. dbt 프로젝트 설정</h3>
    <p class="section-description">dbt 프로젝트를 초기화하고, Vertica 데이터베이스 접속 정보를 담은 프로파일을 설정합니다.</p>
    <div class="syntax-box">
      <strong>[as root] dbt 프로젝트 초기화:</strong>
      <pre><code>cd /opt
dbt init my_hop_dbt</code></pre>
      <strong>[as root] 접속 프로파일 생성 (~/.dbt/profiles.yml):</strong>
      <pre><code>my_hop_dbt:
  outputs:
    dev:
      type: vertica
      host: &lt;VERTICA_HOST_IP&gt;
      port: 5433
      username: vertica  # dbt-vertica에서는 user 대신 username 사용
      password: "&lt;DB_PASSWORD&gt;"
      database: &lt;DB_NAME&gt;
      schema: public
      threads: 1
  target: dev</code></pre>
    </div>
  </div>

  <div class="architecture-subsection">
    <h3 class="section-subtitle">3. dbt 모델링 예제</h3>
    <p class="section-description">dbt의 핵심 기능인 모델(SQL 파일)과 매크로를 사용하여 데이터 변환 로직을 정의합니다.</p>
    <div class="syntax-box">
      <strong>기본 테이블 모델 (models/order_summary.sql):</strong>
      <pre><code>{% raw %}{{ config(materialized='table', schema='test') }}

SELECT 
    customer_id,
    COUNT(order_id) as total_orders,
    SUM(amount) as total_spent
FROM public.orders
GROUP BY 1{% endraw %}</code></pre>
      <strong>증분 모델 (Incremental Model):</strong>
      <p class="section-description" style="margin-top: 0.5rem; margin-bottom: 1rem;">마지막 실행 이후 추가된 데이터만 처리하여 변환 작업의 효율성을 높입니다.</p>
      <pre><code>{% raw %}{{ config(
    materialized='incremental',
    unique_key='customer_id'
) }}

SELECT 
    customer_id,
    COUNT(order_id) as total_orders,
    SUM(amount) as total_spent
FROM {{ source('raw_vertica', 'orders') }}

{% if is_incremental() %}
  -- this: 현재 모델(order_summary)을 의미
  WHERE order_date >= (select max(order_date) from {{ this }})
{% endif %}

GROUP BY 1{% endraw %}</code></pre>
    </div>
  </div>

  <div class="architecture-subsection">
    <h3 class="section-subtitle">4. dbt 실행 및 확인</h3>
    <p class="section-description">dbt 명령어를 사용하여 프로젝트 설정을 검증하고, 정의된 모델을 실행하여 Vertica에 테이블을 생성합니다.</p>
    <div class="syntax-box">
      <strong>dbt 실행 및 Vertica 확인:</strong>
      <pre><code># 1. dbt 프로젝트 설정 및 DB 연결 테스트
dbt debug

# 2. 프로젝트의 모든 모델 실행
dbt run --project-dir /opt/my_hop_dbt

# 3. 특정 모델만 선택하여 실행
dbt run --select order_summary

# 4. Vertica에서 결과 확인
-- vsql -c "select * from test.order_summary;"
--      customer_id | total_orders | total_spent
--     -------------+--------------+-------------
--                1 |            2 |     1525.50
--                2 |            1 |      990.00</code></pre>
    </div>
